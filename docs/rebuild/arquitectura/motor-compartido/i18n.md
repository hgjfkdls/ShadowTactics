# Sistema de i18n (Internacionalización)

## Propósito
Soporte multilingüe para el juego. Actualmente implementa español e inglés. Proporciona una función de traducción y recursos organizados por idioma.

## Archivos Clave
| Archivo | Rol |
|---|---|
| `shared/i18n/index.ts` | `l()`: función de traducción, locale management |
| `shared/i18n/types.ts` | Tipos de traducción |
| `shared/i18n/resources/es.ts` | Recursos en español |
| `shared/i18n/resources/en.ts` | Recursos en inglés |

## Uso
```typescript
import { l } from '@shared/i18n';

// Traducción simple
l('unit.archer.name'); // "Arquero" (es) / "Archer" (en)

// Con parámetros
l('combat.hit', { unit: 'Arquero', target: 'Infantería' });
```

## Recursos
Los archivos de recursos contienen pares clave → valor para todas las cadenas del juego:
- Nombres de unidades, habilidades, cartas, identidades
- Textos de UI (botones, títulos, descripciones)
- Mensajes de combate y eventos
- Descripciones de reglas

## Dependencias
| Dependencia | Tipo |
|---|---|
| Ninguna | — |

## Acoplamiento
- **Nulo**: sistema completamente independiente
- Es usado por múltiples subsistemas del motor (phases/deployment, actions/card, actions/ability, passive) y por el cliente (sonido, UI)
- La función `l()` se importa donde se necesite sin restricciones
- `es.ts` es el recurso principal (juego desarrollado originalmente en español)
